# DESIGN.md library

Design-system write-ups of real websites (colors, type, spacing, components),
copied from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
at commit `f696123`. MIT licensed — see `LICENSE`.

Use one when building a site: "build sites/<name> in the style of design-md/stripe/DESIGN.md".
To refresh, re-copy the `design-md/*/DESIGN.md` files from upstream and update the commit above.
