# prompts/

The coach loads three files from this folder. They are gitignored, because the
repository is public and they contain Olly Olly pricing and sales material.
Download them from Google Drive as plain text or Markdown and save them here
under these exact names:

| File | What it is |
|---|---|
| `coach-instructions.md` | The coach's system prompt. If the file has a `-----` line, only the text below it is sent, as the file itself says to do. |
| `playbook-hormozi-miner-voss.md` | NEPQ, Hormozi, and Voss playbook (loaded as context) |
| `offer-reference.md` | Growth / Strategic / Elite pricing and terms (loaded as context) |

The app won't start a call until all three are present.
